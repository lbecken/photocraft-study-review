## Is a TOML literal string right for every path these tests produce?
The path is `<CARGO_TARGET_TMPDIR>/t005-acc/ac12/outsidedep` (and `t005-guard/ac10/outsidedep`), built with
`Path::join`, not canonicalised (`acceptance_t005.rs:684`, `guard_t005.rs:120`, `:20`).
- Backslashes (Windows): literal strings take them verbatim — this is the fix.
- Spaces: fine in a literal string.
- `\\?\` prefix: fine textually; it does not occur, since nothing canonicalises the path.
- Trailing backslash: fine in a literal string (it is a basic string's escape problem only); and `join` leaves
  none.

  basic string broke on `"` and `\`). The runners' path is `D:\a\<repo>\<repo>\target\tmp\…` (record round 3)
  and a GitHub repository name cannot contain `'`; the Linux and macOS runners' paths likewise. A local checkout
  under a directory with `'` would break it on any platform — not a runner case; noted, not a finding.
