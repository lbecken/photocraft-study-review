## What a first-time user trips over
1. `kiln-cli --help` fails with exit 2 (N-1).
2. `exec --root` looks like the way to edit a file, but nothing it does persists; editing needs
   `run` or `control` (SG-4).
3. Document ids are per session and must be predicted in a script (1, 2, …). The doc's worked
   example shows this, but it never says it outright.
4. Symlinks lead out of `--root`, contrary to the doc (D-1).
