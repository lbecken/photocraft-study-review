### Differential run
Driver of my own (not the builders' generators): per seed a root of 6–14 files, always
containing `a`, `a.txt`, `dir/a`, `dir/a b` (prefix pairs), the rest generated from 1–5 pieces of
the alphabet `a b x Q 7 - _ (inner space) é (U+00E9) e+U+0301 U+200D (ZWJ) ﬃ (U+FB03) ﬁ (U+FB01)
漢字 😀 שלום سلام ٣`, an optional `.txt`/`.rs` suffix, 30 % in a directory `d/` or `dé/`; no
normalization or case-only collisions (NFC + casefold), no line break. Steps (weights): control
`doc.open` (20 %, also of open documents: `already_open`), tab click (15 %, 20 % secondary, 20 %
with `shift`), `Documents` click (10 %), `Close` (15 %), `Discard` (6 %, when shown), focus
`Editor` + type one of `z é ש 😀` (10 %), focus + `ctrl+S` (6 %), control `doc.insert` into any
document (6 %), control `doc.save` of any document (4 %: a save from another path), control
`doc.close` with or without `discard` (5 %: an external close, refused when dirty), `scroll` on
`Tabs` (3 %). Size 1600x1200. After every step a snapshot is compared with the model: tab labels
and order, the one `toggled` tab, `Title` prefix, `modified` and `Discard` per tab, no `value` on a
tab, a `Close` per tab painting no text, no other node in a tab's group, `Message` cleared after a
successful UI close and beginning with `unsaved_changes` after a refused one, and the tab's rows
equal to its path for names not beginning with right-to-left text or `٣`. The log is split per
step by a `buffer.text` marker: switches send no mutating request and a read names the new
document; a UI close logs exactly `{"doc":id}`, a discard `{"discard":true,"doc":id}`, a refused
close nothing. A mismatch prints seed, step, the step's action and the difference. Counts over
the 200 sessions: 1,131 tab clicks, 776 `Documents` clicks, 1,159 `Close` clicks, 140 `Discard`
clicks, 1,047 typed texts, 428 saves by key, 434 control inserts, 319 control saves, 347 control
closes, 227 scrolls. Result: 0 mismatches. (The marker is itself a change by the binary's rule,
finding 3, so per-step "nothing logged" checks were made in separate paired sessions instead.)
