| D-1 | defect | `crates/kiln-workspace/src/disk.rs`:173, :192, :242; `docs/protocol/paths.md`:71 | The walk starts from the root path stored at construction and assumes it is symlink-free; every `lstat` is on an absolute path, so the kernel silently follows a symlink that has since replaced the root or one of its ancestors, while `inside()` compares the stored text and says inside. Fix: re-validate the root on every call (walk from `/` over the stored root's components with `lstat`, refusing a symlink or non-directory as `OutsideRoot`, or compare `fs::canonicalize(root)` with the stored root first) and add a test that swaps the root for a link between two requests; or, if the director rules the root's ancestors out of scope, narrow paths.md:71 and the threat model to "below the root". |
| D-2 | defect | `docs/protocol/paths.md`:48–50 (also :39–40) | "without opening them, so a FIFO never makes a request wait" states more than the code keeps: a FIFO swapped in between the `lstat` and the `open`/`OpenOptions::write` (disk.rs:336, :372) blocks the call, which D-3 accepts and paths.md:70–71 itself admits.
