### Ruling y5 (reproduced; finding 1)
Deterministic, the same on every run (three runs of `$S/y5/y5.py`, identical output md5
`25fb3412cf59d3cb3b4ee918f1a60a7e`). `kiln script` with `src/a.rs`, focus `Editor`, type `y`,
snapshot: `Title` value `src/a.rs — modified — Kiln`, row text `src/a.rs — modifeid — Kiln`.
With 17 dirty documents of different names, 8 `Title`s read `modifeid`; typed into `Path`,
`modified fi office affine fjord fle fifty efficient profile fix …` is reported with
`efcfiient`, `fxi` and `xxy`. The editor (monospace) is affected too, contrary to the implementer's
log: `éb` → `eb́`, `ab́cd` → `abbcd`, `x‍yz` → `xxyz`, `٣٣` → `٣٣٣`,
`٣٣ ab` → `ba ٣٣٣ ab` (rows longer than the line).

Cause, shown by a temporary `eprintln!` in `observe.rs` (restored; `git status` clean): egui 0.37
lays text out with harfrust shaping (`epaint-0.37.0/src/text/text_layout.rs:229-400`).
(a) The proportional font has an `fi` ligature: the glyph `f` gets the ligature's advance and the
`i` becomes a zero-width "continuation glyph" placed at `round(pen x)`
(`emit_continuation_glyphs`, `:483-509`), while the next glyph `e` is placed at its
subpixel-binned `x_px`, one point to the left: `'f' x0=97`, `'i' x0=106 (no pixels)`,
`'e' x0=105`. `merge_rows` (`crates/kiln-ui/src/observe.rs:346-349`) sorts each row's glyphs by
`x0`, so `e` comes before `i`. The same happens to a precomposed `é` + its continuation `́`.
(b) epaint sets `glyph.chr` to the **first char of the cluster** for every glyph shaped in it
(`:256-259`); `text_rows` (`observe.rs:385-403`) reports `glyph.chr`, so a mark or a ZWJ shaped
as its own glyph is reported as its base char. (c) A run that starts with an Arabic-Indic digit
gets one glyph more than it has chars (galley `"٣٣"`: 3 glyphs, the last at x 16 with no pixels),
and the observation reports it. What it can affect: the `rows` of every node in proportional type
(`Title`, `Path`, `Open`, `Message`, `Documents` children, buttons and labels of later panels),
the `Editor` rows for combining marks, joiners and RTL/AN text, the `at` column of `click`
(column → glyph in sorted order: on `ab́cd`, `at col 2` puts the head at 3), and any test
that compares row texts with values (T-055 `w3d`, `label_contains` on rows).
