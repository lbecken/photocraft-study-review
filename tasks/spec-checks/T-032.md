Today the message `command `<name>` panicked` is chosen because `message == PANICKED`
(`kiln-control/src/lib.rs:312–313`). AC-6 says "via `InternalReason::Panic`" but does not say
whether the message is rewritten for every `Internal{Panic}` or only for the `PANICKED` text.

message.

*Add to "Kinds and the generated list" (after T-032:131):* "An `Internal { reason: Panic, .. }`
is reported with message `` command `<name>` panicked ``, whatever its own message; the host
constructs it with `PANICKED` as today."

**4. ambiguity — table cells against generated descriptions after later tasks.**

T-008 rewords the `not_a_file` description *and* the table cell (T-008:122). T-010 widens the
`out_of_range` description but "`docs/control-protocol.md` is not touched" (T-010:14, :104). So

*Append to the second replacement sentence (T-032:147):* "Where a row's 'When' text differs
from `error_kinds`, `error_kinds` governs; later tasks do not edit table cells." In T-008, also
delete the clause "Also reword the `not_a_file` 'When' cell … (this task already touches that
file)" (T-008:122).
